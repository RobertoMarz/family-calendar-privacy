# Family Calendar information pages

Public privacy and account-deletion request information for Family Calendar.

This repository contains only:

- `index.html` — privacy policy and contact information.
- `delete-account.html` — instructions for requesting account/data deletion.
- `.nojekyll` — serves the HTML directly through GitHub Pages.
- `README.md` — this description.

Support and privacy contact: **martygamingbuisness@gmail.com**.

Email links open the visitor's email composer. They do not automatically send a request or delete an account. Requests are verified and handled manually by the app operator.

These pages contain no Android app source, appointments, authentication credentials, database keys, forms, analytics scripts, or database connections. GitHub may collect visitor information for hosting security; see [GitHub Pages data collection](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages#data-collection).

To publish, enable GitHub Pages for the repository's main branch and root folder. Verify both live page addresses before entering them in Google Play Console. Keep the public policy current when the app's data handling or contact information changes.
